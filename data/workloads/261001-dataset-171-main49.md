## Corpus and coverage

The current source corpus contains **171 apps**, with one package name and one source
version per app. Of these, **150 apps contain 5,890 eligible source occurrences**;
the other 21 apps contain no sources identified by the inventory rules.

The [source archive manifest](../source-archives-manifest.csv) lists the 171 retained
archives and their package names. The [checksum list](../source-archives-sha256.txt)
records their SHA-256 values. The [corpus summary](../source-corpus-summary.json)
records the counts and coverage denominators. The [source inventory](../source-inventory.jsonl)
contains the 5,890 retained occurrences with archive-relative source locations.

Run `uv run python scripts/verify_source_corpus.py` from the repository root to verify
archive membership, inventory counts, benchmark source locations, and coverage.

## Workload selection

Main49 retains the 49 apps with the largest source inventories in the current corpus.
Apps are ranked by descending source-occurrence count, with ties broken by ascending
app ID. All source occurrences from each selected app are retained.

Strat15 retains its fixed 15 apps, all 1,284 occurrences, and their execution order.
The following deterministic rule reproduces its membership from Main49:

1. Use the Main49 ranking described above.
2. Partition the ranking into consecutive bands of at most ten apps.
3. For a band of size `m`, select the one-based positions `round_half_up(0.3*m)`,
   `round_half_up(0.6*m)`, and `round_half_up(0.9*m)`.
4. Retain every source occurrence of each selected app in the benchmark's existing
   execution order.

| Main49 rank band | Band size | Within-band positions | Global ranks |
| --- | ---: | --- | --- |
| 1–10 | 10 | 3, 6, 9 | 3, 6, 9 |
| 11–20 | 10 | 3, 6, 9 | 13, 16, 19 |
| 21–30 | 10 | 3, 6, 9 | 23, 26, 29 |
| 31–40 | 10 | 3, 6, 9 | 33, 36, 39 |
| 41–49 | 9 | 3, 5, 8 | 43, 45, 48 |

The position rule is deterministic and involves no random draw.
`select_strat15_by_relative_rank` in `scripts/build_public_benchmarks.py` implements
it using integer arithmetic and verifies the generated cases against the fixed
Strat15 reference.

## Candidate grid and source-subtype TVD

Candidate schemes use a common triple of relative positions from the grid
`10%, 20%, ..., 100%`. Each strictly increasing triple is applied to every band.
For an integer percentage `p` and a band of `m` apps, the one-based position is
`floor(p*m/100 + 0.5)`, implemented as `(p*m + 50) // 100`.
A scheme is valid only if all five bands receive three distinct, in-range positions.
Of the 120 percentage triples, **112 are valid**; eight map two positions to the
same app in the nine-app band.

Each source occurrence has equal weight. For each scheme, source-subtype counts
are normalized by its own total source count and compared with the distribution
over all 4,649 Main49 occurrences. TVD is `0.5 * sum(abs(p[k] - q[k]))`, evaluated
over the 26 subtypes represented in Main49; a subtype absent from a candidate
has count zero. The script compares exact rational TVD values without a
floating-point tolerance.

Application source-count ties are ordered by ascending app ID. Equal TVD values
share rank `1 + the number of strictly smaller values`. All exact minimizing
triples are reported; the lexicographically smallest percentage triple is selected
if multiple minima occur. The current result has a **unique minimum**:

| Relative positions | Apps | Source occurrences | Source-subtype TVD | Rank |
| --- | ---: | ---: | ---: | ---: |
| 30%, 60%, 90% | 15 | 1,284 | 0.07677244763051579 | 1 |
| 30%, 60%, 80% | 15 | 1,290 | 0.08240865335714441 | 2 |

The minimum is exactly `458279 / 5969316` (approximately **0.0768**).
It applies to the 112 valid schemes in this defined grid. The selected cases,
including every field and their execution order, match the published Strat15
template exactly.

The [complete sampling analysis](../strat15-sampling-analysis.json) records the
input hashes, app ranking, all 112 candidate scores, tied minima, and selected apps.
Recompute and verify it with:

```bash
uv run python scripts/analyze_strat15_sampling.py --check
```

Use `--write` to regenerate this JSON from the published benchmark templates.
`scripts/verify_source_corpus.py` also runs this check.
